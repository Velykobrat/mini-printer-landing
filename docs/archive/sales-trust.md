## Реалізація

- Одна конфігурація `shared/sales-content.js`: підтверджені умови, pending-поля, комплектація, lifestyle, FAQ, video та production-відгуки. Ціна й API залишаються окремими й незміненими.
- `scripts/sync-sales.mjs` створює статичні секції в HTML; `npm run sync:sales` оновлює їх, `npm run check` перевіряє узгодженість. Динамічний компонент `sales.js` потрібен лише для відгуків; текст вставляється через textContent.
- Доставка/оплата та комплектація без непідтверджених обіцянок. Попередні три кроки доставки замінено одним блоком, а не продубльовано.
- Три додаткові сценарії: фото/спогади, навчання/плани, наліпки/порядок. Наявне lifestyle-фото використане для організації; для перших двох сценаріїв — явні текстові fallback. Наявні оригінальні фото не змінено; AI та сторонні картинки не використовувалися.
- Сім семантичних details/summary у наявній FAQ-секції. Відгуки: production без підтверджених даних прихований; локальний `?reviews=demo` показує три приклади з явним попередженням. На зовнішньому hostname demo недоступний. Рейтингів, review schema і вигаданих покупців немає.
- Виправлено хибний CRLF drift у product sync; додано .gitattributes. Dev server підтримує правильні MIME та byte ranges для відео, зберігаючи offline API.
- README актуалізовано до фактичного main; історичні QA/GA4/attribution записи позначено як історичні, їхні результати збережено.

## Перевірка медіа

У поточному дереві були три JPEG 630×630; додаткових відеофайлів серед доступних матеріалів цієї робочої директорії не було. Історія Git містить:

- `images/portatyvnyi_printer_jetix_mini.mp4`, blob `a42917f284c52a5ed35ab0ce0f9f885afba417b7`, 4 066 161 байт;
- `images/portativnyi_termoprinter_jetix.mp4`, blob `546ccf98fb9fd86b59760ef8c2c1673a60326f4a`, 60 532 648 байт.

Обидва були видалені в `0a7e651`. Менший файл з дерева `82bd482` відновлено без перекодування як `images/mini-printer-demo.mp4`: 1280×720, 68.708 с. У Chrome переглянуті кадри на 2/10/20/30/40/50/60 с: показано принтер, інтерфейс смартфона й приклади друку. Це архівний рекламний відеоогляд, не незалежний тест якості; не слід виводити з нього нові технічні чи комерційні обіцянки. Різні кольори в ролику не є підтвердженням наявності; під відео є пояснення. Більший файл не повертався на сайт.

Відео має локальний poster, controls, playsinline, preload=none, без autoplay. Chrome підтвердив: до ручного запуску MP4 не завантажується, після запуску відтворюється й перемотується. Для майбутньої заміни рекомендовано власну реальну зйомку друку: MP4 H.264/AAC, 1280×720 або 1920×1080, 20–45 с, бажано до 5–8 МБ, WebP/JPEG poster; шлях `images/mini-printer-demo.mp4`. Додайте субтитри, якщо є озвучені інструкції. Без файла встановіть video.status=pending та src=null, залиште poster і виконайте sync:sales — з’явиться чесний fallback.
